Choose WebSocket or HTTP updates. Go sends new inner HTML for just the count and its hidden state container. The rest of the page stays in place.

// Parse HTML. Find an element. Make it yours.
page, err := live.Parse(markup)
if err != nil {
    return err
}

page.GetElementById("count").SetTextContent(count)
if err := h.Render(http.StatusOK, page); err != nil {
    log.Printf("render counter: %v", err)
}

Without JavaScript, the same form redirects to the updated page. Each request gets its own tree; your template file stays untouched.
