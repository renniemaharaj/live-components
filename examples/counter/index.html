The form sends the count to a go-api-kit route. Go changes the value, redirects here, and updates a fresh HTML tree with Live Components.

// Parse HTML. Find an element. Make it yours.
page, err := live.Parse(markup)
if err != nil {
    return err
}

page.GetElementById("count").SetTextContent(count)
if err := h.Render(http.StatusOK, page); err != nil {
    log.Printf("render counter: %v", err)
}

The count travels in the form and URL. Each request gets its own tree; your template file stays untouched.
