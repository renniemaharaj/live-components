          How to read these measurements
          
Throughput counts verified workload units, not a mixture of DOM calls, renders, and HTTP requests. Local timing excludes setup and correctness checks; throughput includes the complete running loop. Percentiles are histogram upper bounds (at most 3.125% bucket width). Allocation and heap counters cover this Go process, including dashboard activity. Prepared nodes are counted from the rendered workload dataset. They do not include transient clones. Shared mutation is unsupported; immutable shared reads and independent instances are separate scenarios. Endurance results include a post-GC heap sample, not a claim that retained memory is a leak. Limits: 10,000 components, 2,000,000 work items per suite, 1,000 requested workers, 120 seconds, and a sampled 512 MiB heap guard. History is bounded and kept only in this process.
